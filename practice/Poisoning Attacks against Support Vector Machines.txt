IMPLEMENTATION 1: HEURISTIC ATTACK (INTUITIVE, VISUAL)
-------------------------------------------------------------------------------

Google Colab Notebook:
https://colab.research.google.com/drive/1d0z6_KkQys0-CLarB3RmFa_lCR97BFLO

WHAT THIS CODE DOES:
A clean, minimal, highly visual implementation of SVM poisoning.
Uses a simple heuristic instead of the exact gradient: move the attack point
AWAY from support vectors of the attacked class.

Designed for INTUITIVE UNDERSTANDING — works beautifully on 2D data.

-------------------------------------------------------------------------------
EXPERIMENT: Synthetic 2D Gaussian Data
-------------------------------------------------------------------------------

STEP 1 — DATA GENERATION:

Class  | Label | Center     | Covariance | Points
-------|-------|------------|-----------|--------
Red    | -1    | [-1.5, 0]  | 0.6 * I   | 25
Blue   | +1    | [1.5, 0]   | 0.6 * I   | 25

Training: 25 points | Validation: 25 points

STEP 2 — INITIAL SVM:
Linear SVM, C = 1.0
- Training accuracy:     ~0.92
- Validation accuracy:   ~0.92
Decision boundary: vertical line near x = 0

STEP 3 — ATTACK INITIALIZATION:
- Attacked class: +1 (blue)  — we want to hurt this class
- Attack class:   -1 (red)   — poisoned point will have this label
- Initial point: first blue training point, label flipped to red
- Start: [0.63, 0.03] as red point inside blue cluster

STEP 4 — HEURISTIC GRADIENT ASCENT:

At each iteration:
1. Inject current attack point into training set (label = -1)
2. Train SVM on poisoned data
3. Compute hinge loss on validation set
4. Find support vectors of attacked class (+1)
5. Move attack point:

--------------------------------------------------------------------------------
direction = attack_point - mean(positive_support_vectors)
attack_point += step_size * direction
--------------------------------------------------------------------------------

Why it works: Moving away from positive SVs pushes decision boundary into
positive region → more positive validation points misclassified → hinge loss ↑

This is NOT the exact gradient, but approximates uphill direction.

STEP 5 — VISUALIZATIONS:

1. ATTACK TRAJECTORY:
   - Black line: path of attack point
   - Green square: start (blue point labeled red)
   - Red star: final (deep in red territory)
   - Decision boundary shifts LEFT as attack progresses

2. LOSS EVOLUTION:
   - Initial hinge loss:  ~0.125
   - Final hinge loss:    ~0.236 (30 iterations)
   - Monotonic increase → heuristic works

3. BEFORE/AFTER COMPARISON:
   - Clean SVM: boundary at x≈0
   - Poisoned SVM: boundary shifted left
   - Validation accuracy: 0.92 → 0.88 (4% drop)

IMPLEMENTATION 2: EXACT GRADIENT ATTACK (MATHEMATICALLY PRECISE)
-------------------------------------------------------------------------------

Google Colab Notebook:
https://colab.research.google.com/drive/1CxBFmIm7pPCFAxK-BIn2TB0WvWsaTw8q

WHAT THIS CODE DOES:
Complete replication of Biggio 2012 with EXACT gradient from Equation (10).
Two experiments: 2D Gaussian (visual) + MNIST 7vs1 (high-dimensional).

-------------------------------------------------------------------------------
EXPERIMENT 1: Synthetic 2D Gaussian Data (Section 3.1)
-------------------------------------------------------------------------------

Same data as heuristic version, but with EXACT gradient:

dL/dx_c = (Mk @ dQsc + dQkc)

Where:
- Mk depends on inverse kernel matrix over support vectors
- dQsc: derivative of kernel between SVs and attack point
- dQkc: derivative of kernel between validation point and attack point
- Only active validation points (hinge loss > 0) contribute

RESULTS:
- Clean decision boundary at x≈0
- Attack point follows mathematically optimal path
- Hinge loss increases monotonically
- Decision boundary visibly shifts left

-------------------------------------------------------------------------------
EXPERIMENT 2: MNIST Binary Classification (7 vs 1)
-------------------------------------------------------------------------------

SCALING TO HIGH DIMENSIONS:

Dataset:
- MNIST digits: 7 (negative, -1) vs 1 (positive, +1)
- 784 features (28x28 pixels)
- Training: 100 samples
- Validation: 500 samples
- Test: remainder

Preprocessing:
- Pixel values normalized to [0,1]
- StandardScaler (critical for linear SVM)

ATTACK EXECUTION:

At each iteration:
1. Train SVM on current poisoned training set
2. Compute exact poisoning gradient (Equation 10)
3. Update attack point: xc = xc + step · (grad / ||grad||)
4. APPEND poisoned point to training set (dataset grows)
5. Track accuracy on train/validation/test sets

KEY FINDING:

Even on high-dimensional real data (784 features):
- ONE carefully crafted point
- Test accuracy drops from ~98% → ~85%
- Under 50 iterations
- Poisoned sample = unrecognizable noise, not a digit

VISUALIZATIONS:
- Accuracy degradation curves (train/val/test)
- Final poisoned image — looks like random noise
- Support vector statistics after attack
