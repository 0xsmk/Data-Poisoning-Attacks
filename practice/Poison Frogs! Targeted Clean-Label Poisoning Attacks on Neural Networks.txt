WHAT THIS CODE DOES:
Replicates the clean-label, targeted poisoning attack from the Poison Frogs paper.

THE ATTACK GOAL:
Inject visually clean poison images into the training set → cause a specific
test image to be misclassified at test time.

KEY CONSTRAINT:
Poison images have CORRECT labels. No human would spot them as malicious.

-------------------------------------------------------------------------------
EXPERIMENT SETUP
-------------------------------------------------------------------------------

Dataset:       CIFAR-10
Target class:  airplane (class 0) — the image we want to misclassify
Base class:    frog (class 6)     — we want target to be misclassified as frog
Target image:  Random airplane from test set
Poison images: 50 frog images from training set, watermarked with target airplane
Model:         Small CNN (3 conv layers + classifier)
Training:      10 epochs, Adam optimizer, cross-entropy loss

-------------------------------------------------------------------------------
ATTACK STRATEGY — FEATURE COLLISION
-------------------------------------------------------------------------------

CORE INTUITION:
Create poison images that are:
1. VISUALLY → look like frogs (clean-label)
2. FEATURE-SPACE → close to the target airplane

IMPLEMENTATION:
Linear interpolation (watermark):

--------------------------------------------------------------------------------
poison = (1 - α) · frog + α · target
α = 0.3
--------------------------------------------------------------------------------

RESULT:
- Human sees: a frog (slightly weird, but clearly a frog)
- Network sees: frog features + airplane features → FEATURE COLLISION
- The poison image sits near the target in feature space, pulling the decision
  boundary during training

-------------------------------------------------------------------------------
STEP-BY-STEP WALKTHROUGH
-------------------------------------------------------------------------------

STEP 1 — Train clean model:
- Normal training on clean CIFAR-10
- Establish baseline performance

STEP 2 — Create poison dataset:
- Select 50 random frog images from training set
- Watermark each with target airplane (30% opacity)
- Preserve original label = FROG (clean-label!)
- Result: 50 images that look like frogs but contain airplane features

STEP 3 — Train poisoned model:
- Train on clean data + 50 watermarked frogs
- Identical architecture and hyperparameters
- No special treatment — poison blends into normal training

STEP 4 — Evaluate target image:
- Take the SAME test airplane image
- Run inference through both models
- Compare predictions

-------------------------------------------------------------------------------
KEY RESULT
-------------------------------------------------------------------------------

CLEAN MODEL:
✅ Correctly classifies target airplane as "airplane"

POISONED MODEL:
❌ Misclassifies target airplane as "FROG" (base class)

-------------------------------------------------------------------------------
SUCCESS METRICS
-------------------------------------------------------------------------------

Attack success:      YES — target image flipped from airplane → frog
Poison count:        50 images (0.1% of training data)
Poison visibility:   Imperceptible without side-by-side comparison
Label integrity:     ALL poison images correctly labeled as frog
Retraining required: No — poison works in single training run
